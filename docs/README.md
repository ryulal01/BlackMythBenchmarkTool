# Black Myth: Wukong Benchmark Tool (C#)

Автоматизированный инструмент для запуска бенчмарка Black Myth: Wukong и сбора результатов CPU/GPU тестов.

## Как запустить

1. Установите .NET 8 SDK.
2. Клонируйте репозиторий.
3. Откройте папку `config` и отредактируйте `appsettings.json`:
   - Укажите правильный путь к `BlackMythBenchmark.exe`.
   - Укажите путь к файлу результатов (куда бенчмарк пишет JSON).
4. В терминале в корне проекта выполните:
   ```bash
   dotnet run
